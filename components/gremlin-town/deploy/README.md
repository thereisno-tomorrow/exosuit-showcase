# Deployment templates

Reference scripts and inactive configuration examples for an operator-owned
installation. The public showcase uses none of them: start with the root
quickstart and synthetic offline journey.

Reserved `example.invalid` endpoints, invented addresses, placeholder hashes and
`C:/Example` paths require operator configuration. No live host, credentials,
enrolled account or installation evidence is included.

Installation, routes, backups and restores retain explicit environment gates:
`GT_APPROVED_APPLY`, `GT_APPROVED_PRIVATE_ROUTE`, `GT_APPROVED_PUBLIC_GROK`,
`GT_APPROVED_PC_BACKUP` and `GT_APPROVED_RESTORE`. Review exact scripts and target
paths before using them. A flag is neither another operator's authorization nor
a guarantee of reversibility.

Helpers illustrate artifact hashes, immutable releases, preimage verification
and isolated readability checks. They are not a portable deployment system.
Choose and validate your own service user, directory layout, container topology,
network routes, backups and rollback.
